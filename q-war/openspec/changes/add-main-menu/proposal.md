# 添加主界面

## Why

当前游戏以测试场景（TestScene）为入口，缺少独立游戏常见的「主界面」入口。为形成最小可玩单元并提升首次进入体验，需要增加主界面，提供开始游戏、设置、玩法说明等入口；本期重点为主界面表现与「开始游戏」按钮的设计与实现。

## What Changes

- **主界面场景**：新增主界面场景（如 MainMenu），作为应用启动后的首个界面；包含标题/品牌区、开始游戏、设置、玩法说明等入口。
- **主界面表现**：本期重点为主界面整体视觉与「开始游戏」按钮的样式、交互反馈（hover/按下）、点击后正确进入当前可玩内容（TestScene/战斗）。
- **设置与玩法说明**：主界面上保留入口（按钮或菜单项）；本期可为占位或极简实现（如弹窗提示「敬请期待」），不展开完整设置页与玩法说明页。
- **启动流程**：将 `run/main_scene` 改为主界面场景；从主界面「开始游戏」再切换到 TestScene（或后续正式战斗场景）。

## Capabilities

### New Capabilities

- `main-menu`：主界面场景的节点结构、布局与表现；开始游戏按钮的样式与点击后切换至战斗场景；设置、玩法说明入口的占位或极简实现；与 project.godot 主场景的衔接。

### Modified Capabilities

- （无。）

## Impact

- **受影响代码/资源**：新增主界面场景（如 `Scenes/MainMenu.tscn`）及对应脚本（如 `Scripts/MainMenu.cs`）；修改 `project.godot` 的 `run/main_scene` 指向主界面。
- **依赖**：Godot 4 场景与 Control/Button 等 UI；无新增第三方依赖。
