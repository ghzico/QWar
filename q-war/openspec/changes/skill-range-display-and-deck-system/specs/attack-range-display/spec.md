# Spec: attack-range-display

## ADDED Requirements

### Requirement: 攻击/技能选择后高亮所有在攻击距离内的格子

选择攻击或技能后，系统 SHALL 高亮显示所有在攻击距离内（曼哈顿距离 ≤ 攻击距离）的格子，不限于格内是否已有敌将。

#### Scenario: 选择攻击后高亮范围

- **WHEN** 玩家选择某棋将的「攻击」且该棋将具有攻击距离 N
- **THEN** 所有与棋将曼哈顿距离 ≤ N 的格子均被高亮（含无单位的格子与有敌将的格子）

#### Scenario: 选择技能后高亮范围

- **WHEN** 玩家选择某棋将的「技能」且该技能使用攻击距离 N
- **THEN** 所有与棋将曼哈顿距离 ≤ N 的格子均被高亮（含无单位的格子与有敌将的格子）

---

### Requirement: 仅当格内有可攻击目标时执行攻击/技能

攻击或技能 SHALL 仅在玩家点击的格子内存在可攻击目标（敌将）时生效；点击范围内无目标的格子 SHALL 不执行攻击/技能。

#### Scenario: 点击有敌将的格子执行攻击

- **WHEN** 玩家已选择攻击/技能且高亮已显示，玩家点击某一高亮格子且该格内有敌将
- **THEN** 系统对该格内目标执行攻击/技能（伤害结算等按现有逻辑），并结束本次攻击/技能选择

#### Scenario: 点击范围内空格子不执行

- **WHEN** 玩家已选择攻击/技能且高亮已显示，玩家点击某一高亮格子且该格内无单位（或无可攻击目标）
- **THEN** 系统不执行攻击/技能；可取消当前选择或保持高亮等待玩家点击其他格子（具体交互由实现决定）

#### Scenario: 执行判定与高亮范围分离

- **WHEN** 系统判断某次点击是否触发攻击/技能
- **THEN** 判定依据为「该格子是否在攻击范围内且格内存在可攻击目标」，而非仅「是否在高亮格内」
