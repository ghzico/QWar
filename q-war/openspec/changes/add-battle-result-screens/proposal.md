# 添加战斗成功/失败界面

## Why

当前战斗结束后无明确结算界面，玩家无法得知胜负结果或进行「回到主菜单」「重新挑战」等操作。为形成完整单局闭环并提升可玩单元体验，需要增加战斗胜利与战斗失败两个结果界面，并明确触发条件与按钮行为。

## What Changes

- **战斗胜利界面**：当场上所有怪物被消灭时显示。包含「战斗胜利！」文本、「回到主菜单」按钮、以及一张结果图（资源路径预留，后续由你放入图片；文档与实现中会标明图片应放置的位置）。
- **战斗失败界面**：当场上仍存在怪物且我方已上场的棋将血量均为 0 时显示。包含「战斗失败...」文本、「重新挑战」按钮、「回到主菜单」按钮、以及一张结果图（与胜利界面相同约定：预留位置，你之后添加图片，文档说明放置路径）。
- **触发与逻辑**：在战斗流程中（如怪物死亡移除、棋将受到伤害导致死亡后）检测胜利/失败条件，满足时弹出对应结果界面；「回到主菜单」切换至 MainMenu 场景；「重新挑战」重新加载当前战斗场景（如 TestScene）。
- **图片占位**：胜利与失败界面各预留一个图片展示区域，资源路径约定为固定目录（见设计/规格），你后续将图片放入该路径即可。

## Capabilities

### New Capabilities

- `battle-result-screens`：战斗胜利/失败界面的布局与内容（文本、按钮、图片区域）；胜利/失败判定时机与条件；回到主菜单与重新挑战的跳转逻辑；结果图资源路径约定与占位策略。

### Modified Capabilities

- （无。）

## Impact

- **受影响代码**：FightBoard 或战斗场景层需在适当时机检测胜负并显示结果界面；新增结果界面场景或 UI 节点及对应脚本（如 BattleResultPanel 或 VictoryScreen/DefeatScreen）；可能新增 `Res/` 下结果图目录。
- **资源**：结果图放置路径由设计/规格约定（如 `Res/UI/` 或 `Res/BattleResult/`），本期为占位，你后续添加图片。
- **依赖**：Godot 4 场景与 UI；无新增第三方依赖。
